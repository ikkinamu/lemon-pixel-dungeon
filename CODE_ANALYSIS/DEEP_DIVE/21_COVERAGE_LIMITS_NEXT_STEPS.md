# 분석 범위, 검증 수준, 남은 확인 항목

## 확보한 범위
- GitHub Git Tree API로 전체 파일 1,952개, Java 파일 1,323개를 빠짐없이 수집해 00~06 색인 문서로 기록.
- 실제 소스 본문을 열어 주요 엔진/게임/맵/전투/아이템/플랫폼/로컬라이제이션/기록 클래스들의 선언과 대표 메서드 구현을 확인.
- 심층 문서 10~20번에 호출 경로·개념·혼동 지점·소스 링크를 작성.
- 소스 코드/자산/기존 빌드 파일에 변경 없음.

## 확인 수준
| 수준 | 무엇을 했는가 | 보장하지 않는 것 |
|---|---|---|
| 전체 경로 인벤토리 | Git Tree로 모든 추적 파일 경로/크기 조회 | 모든 내용 이해 |
| 대표 클래스 정적 분석 | 선택된 핵심 .java의 소스와 선언/코드 조각 확인 | 하위 클래스 전체 동작 |
| 시스템별 흐름 재구성 | 명시적인 메서드 호출과 상속·의존성으로 문서화 | 모든 런타임 경로 증명 |
| 실행 검증 | 수행하지 않음 | 컴파일/실행/저장 호환성/성능 보증 |

## 추가 심층 분석을 권장하는 작업
1. **모든 1,323개 Java 파일의 정확한 선언 목록**: Java 파서(AST)를 이용해 내부 클래스·필드·메서드·오버로드·주석과 선언 라인 추출. 현재 Git Tree 색인은 모든 경로를 담지만 전수 AST를 만들지는 않았음.
2. **모든 호출·상속 그래프**: 단순 import가 아니라 실제 메서드 호출을 AST + 타입 해석으로 구분. 자바의 동적 디스패치/Reflection은 별도 처리.
3. **전투식 전체 추적**: Char.attack, hit, 영웅/몬스터별 override, 장비/버프/재능마다 보정 순서 및 반올림 오차 검증.
4. **던전 생성 재현성 검증**: 같은 seed/버전/선택 조건에서 Level.create와 Generator 상태 비교.
5. **저장 호환성 테스트**: 실제 세이브 Bundle/버전 코드/이전 릴리스 간 복원, 실패와 예외 처리.
6. **플랫폼별 빌드/기기 테스트**: Java/Android/iOS 툴체인, 리소스 및 서비스 연결 확인.
7. **정적 코드 검사**: 경합 가능 지점, 널 참조, 자원 누수, 미사용 선언, 성능 병목 (확정 버그와 '점검 후보' 구분).
8. **원본과 포크 차이 비교**: 상위 Shattered Pixel Dungeon에서 달라진 부분과 추가 기능을 원본과 diff해 기록.

## 정확성 체크
- '확인'은 코드에서 직접 보고 문서에 출처를 링크한 내용만 의미.
- 직접 확인하지 않은 하위 클래스의 특징은 해당 계층의 일반적 역할 설명 또는 **미검증**으로 표시.
- 수치/플래그는 직접 읽은 소스의 값이며 향후 커밋에서 바뀔 수 있음.
- 정적 분석만으로 버그의 존재/수정 필요성을 단정하지 않음.
