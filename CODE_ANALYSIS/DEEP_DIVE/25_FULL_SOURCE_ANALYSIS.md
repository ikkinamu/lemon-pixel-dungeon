## 해석 수준의 한계

- 전체 본문을 읽고 선언 및 호출 식별자 기반 **정적 색인**을 만들었지만, **각 메서드의 정확한 모든 작동/반환값/부작용을 해석 완료한 것은 아니다**.
- 일부 함수는 선언이 여러 줄에 걸쳐 있거나 중첩 클래스·익명 클래스에 있으므로 규칙 기반 추출에서 빠지거나 다른 메서드의 호출이 섞일 수 있다.
- `import`는 **컴파일 의존성**이며 `method()`가 실제 실행되는 것과는 다르다. 호출 후보는 런타임 순서를 보장하지 않는다.
- 빌드·플레이·자동화 테스트, Java AST/타입 해석, 모든 분기 경로 추적은 수행하지 않았다.
- 실제 규칙을 판단할 때는 [09_CALL_CHAINS.md](RELATIONSHIPS/09_CALL_CHAINS.md)에서 확인된 대표 경로와 원본 Java 구현을 함께 확인해야 한다.
